# CLAUDE.md

Цей файл підказує Claude Code (claude.ai/code), як працювати з цим репозиторієм.

## Що це

Односторінковий статичний сайт онлайн-тренера Влада Нагорнюка (українською). Призначений для публікації на Netlify з папки `site/`. Без фреймворків і без runtime-залежностей: Python (лише stdlib, 3.11+ через `tomllib`) потрібен для збірки й локального сервера. Pillow потрібен тільки для `python main.py images`. Документація й коментарі в коді українською, тримайся цього.

Структура й підхід перейняті з еталона `C:\projects\katsko` (той самий принцип `src/ -> site/`, CSP за хешем). Тексти, фото й брендинг власні, нічого з Katsko не копіюємо.

## Команди (з кореня репозиторію)

```
python main.py serve [порт]   # локальний сервер :8830 із заголовками й CSP з netlify.toml (команда за замовчуванням)
python main.py build          # src/ -> site/index.html, robots.txt, sitemap.xml; перераховує хеші CSP у netlify.toml
python main.py check          # код виходу 1, якщо site/ або хеш CSP застаріли відносно src/
python main.py images         # images/ -> site/img/out (webp), плюс og.jpg, favicon.ico, icon-180.png (потрібен Pillow)
```

Тестів-фреймворку немає: сайт перевіряється вручну в браузері (`serve`) і в DevTools на порушення CSP.

## Архітектура

- **Правити лише `src/`.** `site/index.html`, `site/robots.txt`, `site/sitemap.xml` генеруються, руками їх не чіпати. Після будь-якої правки в `src/` запускай `python main.py build` і коміть `src/`, `site/` та `netlify.toml` разом.
- **CSS і JS лишаються inline.** CSP у `netlify.toml` дозволяє тільки inline-скрипти за sha256 (без `'self'`). Збірка склеює `src/styles/*` і `src/scripts/*` в один `index.html` та сама оновлює хеші. Не додавай зовнішні `.js`/`.css` і зовнішні джерела: браузер заблокує скрипти. `python main.py check` ловить розбіжність.
- **Мова шаблонів** (`tools/build.py`): `{{ include "шлях" }}` на окремому рядку (вкладені дозволені, шлях від `src/`) і `{{ ключ }}` зі значеннями з `src/site.json` (`site_url`, `telegram_url`, `instagram_url`, `mono_url`). Нерозкритий маркер зупиняє збірку. Не пиши в `src/` інші `{{ ... }}`.
- Порядок рядків `include` у `src/index.html` задає каскад CSS і порядок виконання JS. Префікси `NN-` у назвах файлів відображають цей порядок: міняй обидва разом.
- `src/scripts/NN-*.js` це незалежні блоки `try { (() => {...})(); } catch (e) { console.error(e); }`, щоб збій одного не ламав решту. Новий блок пиши в такому ж форматі. Виняток: `00-theme-init.js` стоїть у `<head>` окремим `<script>` (щоб тема застосувалась до першого малювання).
- Іконки: SVG-спрайт у `src/partials/icon-sprite.html`, використання `<svg class="ico"><use href="#i-назва"/></svg>`. Емодзі як іконки не використовуємо.
- Дизайн-токени (палітра темної й світлої теми, радіуси, відступи) в `src/styles/02-tokens.css`. Шрифти: Oswald (заголовки) і Onest (текст), самохостяться з `site/fonts/` (кирилиця + латиниця).

## Контент і дані

- Контакти й посилання (Telegram, Instagram, банка monobank) живуть в `src/site.json`. Зміна домену це один рядок `site_url` + `build`.
- Ціни й тексти послуг: `src/sections/services.html`. Кнопки «Оплатити» ведуть на `{{ mono_url }}?a=СУМА&t=ПОСЛУГА` (сума й коментар як параметри). Чи підставляє monobank ці параметри, треба перевірити вручну на реальному пристрої. Якщо ні, кнопка просто відкриє банку без суми.
- Фото результатів: оригінали в `images/` (у `.gitignore`), порядок і відповідність підписам задані в `tools/optimize_images.py` (`RESULTS`) та `src/sections/results.html`.
- Відгуки це перенабрані цитати з `Notes/` без нікнеймів. Скріншоти переписок не публікуємо.
- Портрета тренера на сайті поки немає (слот-заглушка «Н» у `src/sections/about.html`, колаж результатів у герої). Додаючи портрет: оптимізувати в `tools/optimize_images.py`, замінити `.about-visual` / `.hero-visual`.

Шаблон у `.env.example`. **Деплой на Netlify з цього репозиторію не налаштований навмисно**: власник надасть новий project id пізніше. Нічого не деплой без прямого прохання.
